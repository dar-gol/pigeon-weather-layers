# Contributing

Contributions are accepted under the Apache-2.0 license of this project. The
project does not require a CLA at this time.

Before submitting a change:

1. Run `npm run check`.
2. Add or update focused tests.
3. Update README or format documentation when a public contract changes.
4. Do not commit production weather data, credentials, or signed URLs.

Named TypeScript classes, interfaces, type aliases, and enums live in
separate, descriptively named files. Avoid generic `types.ts`, `utils.ts`, or
`helpers.ts` modules.
